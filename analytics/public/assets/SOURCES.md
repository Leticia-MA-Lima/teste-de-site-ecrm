# Fontes dos recursos

`brasil.geojson`: IBGE, API de Malhas Geográficas v3, Brasil com divisões por UF, qualidade mínima. Obtido em 05/10/2026. Uso e redistribuição com crédito ao IBGE; consultar política de uso do portal e documentação antes de alterar a atribuição.

https://servicodados.ibge.gov.br/api/docs/malhas?versao=3

https://servicodados.ibge.gov.br/api/v3/malhas/paises/BR?formato=application/vnd.geo%2Bjson&qualidade=minima&intrarregiao=UF

`logo.png`: recurso já presente no repositório do site eCRM, `images/cropped-Logo-eCRM-WEB.png`. Confirmar com a equipe se esta é a versão oficial para o painel.

Fontes Montserrat e League Spartan: repositório oficial Google Fonts, diretórios `ofl/montserrat` e `ofl/leaguespartan`. Redistribuídas sob SIL Open Font License 1.1; licenças incluídas nos arquivos `*-OFL.txt`. Os arquivos TTF são servidos localmente, sem chamadas ao Google Fonts no navegador.

https://github.com/google/fonts/tree/main/ofl/montserrat

https://github.com/google/fonts/tree/main/ofl/leaguespartan

Não há catálogo de coordenadas de cidades. O mapa apresenta o contorno real e o ranking, sem posicionar cidades por estimativa.
